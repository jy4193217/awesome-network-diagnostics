# Contributing Guidelines

Thanks for considering a contribution to Awesome Network Diagnostics!

## What to add

- Tools that help diagnose, monitor, or troubleshoot network issues
- Online services accessible without sign-up
- Educational resources (guides, books, RFCs) that explain network concepts

## Quality bar

- **Actively maintained**: open source projects must have activity within the last 12 months
- **Free or freemium**: commercial tools are accepted only if they offer a meaningful free tier
- **No affiliate links**: links must be direct, not through referral programs
- **Working**: please verify the link before submitting

## Format

Each entry follows this format:

`- [Tool Name](https://link.to/tool) - One-sentence description ending with a period.`

Within each section, entries are sorted alphabetically.

## How to submit

1. Fork this repository
2. Add your entry in the appropriate section, keeping alphabetical order
3. Open a pull request with a brief explanation

For questions or discussion, please open an issue first.
